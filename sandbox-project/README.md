# Panel sandbox

This project opens in the test IDE so the panel has something to work on.
Nothing here matters: feel free to break these files during testing.

## Files with the same name, for the "open in editor" links

Ask the agent to name them, or type them into the field yourself, and click:

- `Button.js` - three of them: `src/components/Button.js`, `src/legacy/Button.js`, `lib/Button.js`.
  A bare name must offer all three; `components/Button.js` must open the one under components.
- `README.md` - this one and `docs/README.md`.
- `settings.json` - `config/settings.json` and `src/settings.json`.
- `format.js` - only `src/utils/format.js`, so a bare name must open it straight away.
