# Amazing Claude Code GUI

**Claude Code полноценной панелью прямо в IDE от JetBrains.** Карточки вместо терминальной
ленты, файлы, на которые показываешь, вместо путей, которые набираешь, - и код рядом.

Панель запускает тот же Claude Code CLI, что уже стоит на машине, поэтому с ней приезжает всё
привычное: ваш аккаунт, модели, слэш-команды, правила разрешений, серверы MCP и скиллы. Без
прослойки и без нашего аккаунта.

## Почему именно эта панель

- **На файлы показывают, а не набирают их.** Перетащите файл, наберите `@` и выберите из
  проекта, вставьте скриншот - каждый становится капсулой, в которой нельзя ошибиться.
- **Код уезжает вместе с адресом.** Выделите строки, «Send to Amazing Claude Code GUI» - и агент
  прочитает настоящий файл вокруг них, а не кусок без контекста.
- **Любая часть ответа - это ручка.** Процитируйте её в следующем сообщении или ответвите
  разговор ровно с этого места: исходный останется таким, каким был.
- **Видно, что происходит.** Вызовы инструментов с длительностью, диффы с цифрами, список задач,
  который вычёркивается на глазах, планы, субагенты, целый флот агентов внутри одной задачи и
  цена хода.
- **Никакой необъяснимой тишины.** Перегруженный или упёршийся в лимит API рисуется карточкой:
  причина, номер попытки и отсчёт до следующей.
- **Никто не отвечает за вас.** Запрос разрешения, план или вопрос ждут столько, сколько нужно:
  ни таймера, ни автопродолжения.
- **Панель сбоку, а не вкладка редактора** - и её можно поставить к любому краю окна.
- **Разговоры переживают закрытие панели.** Свернули, ушли в другой проект, вернулись - агент
  работал всё это время, а отложенные сообщения так и стоят в очереди.
- **Модель, усилие и режим меняются посреди разговора**, каждый у своей вкладки, без перезапуска.
- **Ответить можно с телефона.** По умолчанию выключено, пара по QR-коду, сквозное шифрование,
  отзыв доступа одним нажатием.
- **Android Studio тоже**, как и любая IDE от JetBrains начиная с 2026.1.

## С чего начать

1. Поставьте Claude Code и убедитесь, что он работает в терминале.
2. Откройте панель с боковой панели инструментов; если вход не сделан, одна кнопка выполнит его
   во встроенном терминале IDE.
3. Пишите: бросайте файлы в поле, `@` - файл проекта, `/` - команда, `!` - запуск в вашей
   оболочке. Модель, усилие и режим - три кнопки под полем.

## Что ещё есть в панели

- **История** прошлых разговоров этого проекта, включая начатые в терминале.
- **Очередь** для сообщений, написанных во время хода; порядок меняется перетаскиванием.
- **Улучшение промпта** - звёздочка переписывает черновик отдельным запуском, не тратя контекст
  разговора, а одна кнопка возвращает ваши слова.
- **Голосовой ввод** по вашему ключу Deepgram: держите горячую клавишу, хоть прямо из редактора.
- **Звуковые сигналы** на семь моментов, которые того стоят, - и только когда вы и так не
  смотрите.
- **Статистика** часов, привычек и достижений, которой можно поделиться картинкой.
- **Девять языков**, по умолчанию - как в IDE.
- **Несохранённые буферы** записываются перед ходом, а изменённые агентом файлы IDE перечитывает
  сразу.

## Приватность и прозрачность

- **Всё работает на вашей машине.** Никакой прослойки и никакого нашего сервера посередине. Вход
  в Claude принадлежит CLI: панель его не читает и не ищет ключи API у вас на диске.
- **Ни телеметрии, ни аналитики, ни аккаунта.** При выключенном удалённом доступе наружу уходит
  только отчёт об ошибке, который вы написали и отправили сами, - и одна кнопка заранее
  показывает его текст целиком.
- **Ваши правила разрешений остаются вашими.** О чём спрашивать, решает CLI по вашим настройкам,
  правилам и хукам. Панель не добавляет своих хуков и не запускает сессию в режиме мягче того,
  что показан на экране.
- **Исходники открыты** на GitHub под Elastic License 2.0, а
  [политика приватности](https://relay.mzpizote.com/privacy) перечисляет всё, что вообще может
  покинуть машину.

## Что нужно

Установленный Claude Code, в который выполнен вход, и любая IDE от JetBrains начиная с 2026.1,
включая Android Studio. У Android Studio нет собственного встроенного браузера, поэтому IDE
предложит поставить браузер от JetBrains вместе с плагином.
