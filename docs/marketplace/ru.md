# Amazing Claude Code GUI

**Claude Code полноценной панелью прямо в IDE от JetBrains.** Карточки вместо терминальной
ленты, файлы, на которые показываешь, вместо путей, которые набираешь, - и код рядом.

Панель запускает тот же Claude Code CLI, что уже стоит на машине, поэтому с ней приезжает всё
привычное: ваш аккаунт, модели, слэш-команды, правила разрешений, серверы MCP и скиллы. Без
прослойки и без нашего аккаунта.

## Почему именно эта панель

- **Круг работ, записанный один раз и выполняемый за вас.** Сценарии: несколько карточек, у
  каждой - собственная сессия Claude - реализовать, проверить, исправить, прогнать тесты - в
  этапах, которые могут повторяться не один раз, а главный поток проходит по ним и судит, что
  нашла каждая. Запустите один нажатием кнопки, три сразу - на три задачи, или по часам в девять
  утра каждый будний день, с ответами на его вопросы, подготовленными заранее. Опишите круг работ
  одной фразой - и Claude прочитает проект и напишет форму.
- **Вся панель с телефона, а не только кнопка «да».** Ответьте на разрешение или план, откройте
  закрытый проект, прочитайте вчерашний разговор, ответвите его, смените модель и усилие,
  переключите аккаунт, войдите в коннектор, продиктуйте сообщение, посмотрите, как идёт сценарий,
  и разблокируйте его. По умолчанию выключено, пара по QR-коду, сквозное шифрование через релей,
  который не прочитает ни слова, отзыв доступа одним нажатием.
- **Несколько аккаунтов Claude переключаются в один клик.** Рабочий и личный - на одной машине,
  без выхода ни из одного. Каждая строка показывает остаток пятичасового окна этого аккаунта и
  его недельного окна, а Select переводит на него все открытые разговоры.
- **Поиск по всем разговорам проекта.** Начала слов, опечатки, основы слов, фразы в кавычках;
  этот разговор или все сразу, с прыжком прямо к сообщению в его разговоре. Когда слов не
  хватает, опишите, что ищете, - и Claude прочитает разговоры за вас.
- **Всё происходящее видно на экране.** Каждый вызов инструмента - с длительностью, каждая
  правка - открытым диффом, субагенты и целые флоты агентов workflow, с разговором каждого агента
  в один клик, список задач, который вычёркивается на глазах, и цена хода. Перегруженный или
  упёршийся в лимит API - это карточка с причиной и отсчётом, а не тишина.
- **Никто не отвечает за вас, и ничего не теряется.** Разрешение, план или вопрос ждут столько,
  сколько нужно - ни таймера, ни автопродолжения. Разговоры продолжаются, даже если панель
  свёрнута или проект переключён, а сообщения, написанные во время хода, ждут в очереди, которую
  держит IDE.
- **Android Studio тоже**, как и любая IDE от JetBrains начиная с 2026.1.

## С чего начать

1. Поставьте Claude Code и убедитесь, что он работает в терминале, - панель запускает именно
   этот CLI.
2. Откройте панель кнопкой на боковой панели инструментов. Если вход не сделан, одна кнопка
   выполнит его во встроенном терминале IDE.
3. Пишите сообщение: бросайте файлы и папки в поле, `@` - файл проекта, `/` - команда, `!` -
   запуск в вашей оболочке.
4. Выделите код в редакторе и выберите «Send to Amazing Claude Code GUI» - в поле уедет точная
   ссылка на файл и строки, а не вставленный текст.
5. Модель, усилие и режим разрешений - три кнопки под полем, и каждая принадлежит той вкладке, на
   которую вы смотрите.

## Что ещё есть в панели

- **На файлы показывают, а не набирают их.** Перетащите файл, наберите `@` и выберите файл из
  проекта, вставьте скриншот или длинный лог - каждый становится капсулой, в которой нельзя
  ошибиться.
- **Код уезжает вместе с адресом.** Выделите строки, «Send to Amazing Claude Code GUI» - и агент
  прочитает настоящий файл вокруг них, а не кусок без контекста.
- **Путь открывает файл.** Путь где угодно в разговоре - в шапке карточки, в ответе, в тексте
  ошибки, в вашем собственном сообщении - открывает файл в редакторе на названной строке, а у
  правки - на месте самой правки.
- **Возьмите любую часть ответа.** Процитируйте её в следующем сообщении, ответвите разговор
  ровно с этого места, закрепите до трёх сообщений над лентой или верните отправленное сообщение
  в поле, чтобы поправить и отправить снова.
- **Модель, усилие и режим меняются посреди разговора** - у каждой вкладки свои, без
  перезапуска. То, с чего стартует новый разговор, можно закрепить самому, а модель со своего
  сервера - добавить вручную.
- **MCP-серверы, плагины и маркетплейсы** - на отдельных экранах: какой сервер поднят, какому
  нужен вход, какой упал и почему.
- **История** прошлых разговоров этого проекта, включая начатые в терминале, открывается с
  конца и подгружается страницами назад по запросу.
- **Очередь** для сообщений, написанных во время хода; порядок меняется перетаскиванием.
- **`!` запускает команду в вашей оболочке**, и её вывод уезжает вместе со следующим сообщением,
  не тратя ход и не спрашивая разрешения.
- **Улучшение промпта** - звёздочка переписывает черновик отдельным запуском, не тратя контекст
  разговора, а одна кнопка возвращает ваши слова.
- **Голосовой ввод** по вашему ключу Deepgram: держите горячую клавишу, хоть прямо из редактора.
- **Звуковые сигналы** на семь моментов, которые того стоят, - и только когда вы и так не
  смотрите.
- **Статистика** часов, привычек и достижений, которой можно поделиться картинкой.
- **Десять языков**, по умолчанию - как в IDE.
- **Несохранённые буферы** записываются перед ходом, а изменённые агентом файлы IDE перечитывает
  сразу.
- **Панель сбоку, а не вкладка редактора**, у любого края окна; цифры выбирают вариант, Shift+Tab
  переключает режим, Escape останавливает ход.

## Приватность и прозрачность

- **Всё работает на вашей машине.** Никакой прослойки и никакого нашего сервера посередине. Вход
  в Claude принадлежит CLI: панель его не читает и не ищет ключи API у вас на диске.
- **Ни телеметрии, ни аналитики, ни аккаунта.** При выключенном удалённом доступе наружу уходит
  только отчёт об ошибке, который вы написали и отправили сами, - и одна кнопка заранее
  показывает его текст целиком.
- **Ваши правила разрешений остаются вашими.** О чём спрашивать, решает CLI по вашим настройкам,
  правилам и хукам. Панель не добавляет своих хуков и не запускает сессию в режиме мягче того,
  что показан на экране.
- **Исходники открыты** на GitHub под Elastic License 2.0, а
  [политика приватности](https://relay.mzpizote.com/privacy) перечисляет всё, что вообще может
  покинуть машину.

## Что нужно

Установленный Claude Code, в который выполнен вход, и любая IDE от JetBrains начиная с 2026.1,
включая Android Studio. У Android Studio нет собственного встроенного браузера, поэтому IDE
предложит поставить браузер от JetBrains вместе с плагином.
