# Amazing Claude Code GUI

**JetBrains IDE の中で、Claude Code をそのままチャットパネルに。** ターミナルの流れる出力ではなく
カードで、パスを打ち込むのではなくファイルを指し示して、しかもコードのすぐ隣で。

動かしているのは、すでにお使いのマシンに入っている Claude Code CLI そのものです。アカウント、
モデル、スラッシュコマンド、権限ルール、MCP サーバー、スキルまで、そっくりそのまま使えます。
間に立つプロキシもなければ、こちらのアカウント登録もありません。

## これを選ぶ理由

- **ファイルは打つのではなく、指し示す。** ドラッグして落とす、`@` と打って選ぶ、スクリーンショット
  をそのまま貼る - どれもチップになるので、打ち間違えようがありません。
- **コードは住所ごと渡る。** エディタで行を選んで「Send to Amazing Claude Code GUI」。エージェント
  は文脈のない断片ではなく、その周りにある本物のファイルを読みます。
- **回答のどの部分も取っ手になる。** 次のメッセージに引用する、あるいはその地点から会話を分岐する。
  元の会話はそのまま残ります。
- **何をしているかが見える。** 所要時間つきのツール呼び出し、増減行数つきの差分、消し込まれていく
  タスクリスト、プラン、サブエージェント、ひとつのワークフロー呼び出しの中で動く多数のエージェント、
  そしてそのターンの費用まで。
- **理由のわからない沈黙がない。** API が混み合ったり上限に当たったりすると、理由・何回目の再試行・
  次までのカウントダウンがカードで出ます。
- **誰かが代わりに答えたりしない。** 権限の確認もプランも質問も、必要なだけ待ちます。時間切れも
  自動継続もありません。
- **エディタのタブではなく、サイドパネル。** ウィンドウのどの端にも置けます。
- **会話はパネルより長生きする。** 畳んでも、別のプロジェクトに移っても、戻ってくればエージェントは
  働き続けていて、順番待ちのメッセージも並んだままです。
- **モデル・思考の強さ・権限モードは会話の途中で切り替わる。** タブごとに独立していて、再起動は
  不要です。
- **スマートフォンから答えられる。** 既定ではオフ、QR コードでペアリング、端末間で暗号化、解除は
  ワンタップ。
- **Android Studio にも対応。** 2026.1 以降のすべての JetBrains IDE で動きます。

## はじめかた

1. Claude Code をインストールし、ターミナルで動くことを確かめます。
2. サイドバーからパネルを開きます。未サインインなら、ボタンひとつで IDE 内蔵のターミナルが処理
   します。
3. あとは書くだけ。ファイルは入力欄に落とし、`@` でファイル、`/` でコマンド、`!` で自分のシェルを
   実行。入力欄の下の三つのボタンがモデル・思考の強さ・権限モードです。

## パネルにあるもの

- **履歴** - このプロジェクトの過去の会話。ターミナルで始めたものも含みます。
- **キュー** - ターン中に書いたメッセージを並べておき、ドラッグで順番を変えられます。
- **プロンプトの改善** - きらめきボタンが下書きを別の実行で書き直します。会話のコンテキストは減らず、
  ボタンひとつで自分の言葉に戻せます。
- **音声入力** - ご自身の Deepgram キーで。キーを押している間だけ、エディタからでも使えます。
- **サウンド通知** - 鳴らす価値のある七つの場面だけ、しかも見ていないときだけ。
- **統計** - 時間、習慣、実績。画像にして共有できます。
- **九言語** - 既定では IDE の言語に従います。
- **未保存のバッファ**はターンの前に書き出され、エージェントが変更したファイルは IDE がすぐ読み直
  します。

## プライバシーと透明性

- **すべて自分のマシンで動く。** 間にプロキシも、こちらのサーバーもありません。Claude へのサイン
  インは CLI のもので、プラグインが読むことも、ディスクの API キーを探し回ることもありません。
- **テレメトリなし、解析なし、アカウントなし。** リモートアクセスがオフなら、外に出るのはご自身が
  書いて送るフィードバックだけ。送る前に、その全文をボタンひとつで確認できます。
- **権限のルールはあなたのもの。** 何を確認するかは、あなたの設定・ルール・フックに従って CLI が
  決めます。プラグインが独自のフックを足すことも、画面に出ているより緩いモードでセッションを始める
  こともありません。
- **ソースは公開**（GitHub、Elastic License 2.0）。マシンから出る可能性のあるものは
  [プライバシーポリシー](https://relay.mzpizote.com/privacy)にすべて挙げてあります。

## 動作環境

インストール済みでサインインした Claude Code と、2026.1 以降の JetBrains IDE（Android Studio を
含む）。Android Studio には内蔵ブラウザがないため、IDE が JetBrains のブラウザプラグインを本
プラグインと一緒に入れるか尋ねます。
