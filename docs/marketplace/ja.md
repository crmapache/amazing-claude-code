# Amazing Claude Code GUI

**JetBrains IDE の中で、Claude Code をそのままチャットパネルに。** ターミナルの流れる出力ではなく
カードで、パスを打ち込むのではなくファイルを指し示して、しかもコードのすぐ隣で。

動かしているのは、すでにお使いのマシンに入っている Claude Code CLI そのものです。アカウント、
モデル、スラッシュコマンド、権限ルール、MCP サーバー、スキルまで、そっくりそのまま使えます。
間に立つプロキシもなければ、こちらのアカウント登録もありません。

## これを選ぶ理由

- **一度書けば、あとは代わりに実行してくれる一連の作業。** シナリオでは、実装・レビュー・修正・
  テスト実行のような、それぞれが独立した Claude セッションであるいくつかのカードを、何度でも
  周回できる段階に並べ、一本の主スレッドがそれらを歩きながら、各カードが見つけたことを判定
  します。ボタンひとつで一つ実行する、三つのチケットに対して同時に三つ実行する、あるいは平日の
  朝九時に、あらかじめ質問への回答を用意したうえで時刻指定で実行する、といったことができます。
  作業内容を一文で説明すれば、Claude がプロジェクトを読んでフォームを書き上げます。
- **「はい」ボタンだけでなく、パネルまるごとをスマートフォンから。** 権限やプランに答える、
  閉じているプロジェクトを開く、昨日のチャットを読む、分岐する、モデルと思考の強さを変える、
  アカウントを切り替える、コネクタにサインインする、音声入力する、シナリオの実行を見守り、
  詰まりを解消する。既定ではオフ、QR コードでペアリング、一言も読めない中継サーバーを介して
  端末間で暗号化、解除はワンタップ。
- **複数の Claude アカウントを、ワンクリックで切り替え。** 一台のマシンで、どちらもサイン
  アウトすることなく仕事用とプライベート用を両立できます。行ごとにそのアカウントの五時間枠と
  週の残りが表示され、Select を押せば開いているすべてのチャットがそのアカウントへ移ります。
- **プロジェクトのすべての会話を横断検索。** 前方一致、誤字、語幹、引用符で囲んだフレーズに
  対応し、この会話だけでもすべての会話でも検索でき、そのままチャット内の該当メッセージへ
  ジャンプします。言葉で言い表せないときは、探しているものを説明すれば Claude が会話を読んで
  探してくれます。
- **していることがすべて画面に出る。** 所要時間つきのツール呼び出し、開いた状態で表示される
  差分、サブエージェント、そしてひとつのワークフロー呼び出しの中で動く多数のエージェントの
  大部隊（それぞれクリックひとつで記録を確認できます）、消し込まれていくタスクリスト、そして
  そのターンの費用まで。API が混雑していたり上限に達していたりしても、黙り込むのではなく、
  理由とカウントダウンをカードで示します。
- **誰かが代わりに答えることはなく、何も失われない。** 権限の確認もプランも質問も、必要な
  だけ待ちます - 時間切れも自動継続もありません。パネルを畳んでも、プロジェクトを切り替えても
  会話は動き続け、ターンの最中に書いたメッセージは IDE が保持するキューで順番を待ちます。
- **Android Studio にも対応**、2026.1 以降のすべての JetBrains IDE で動きます。

## はじめかた

1. Claude Code をインストールし、ターミナルで動くことを確かめます。パネルが動かすのは、その CLI
   そのものです。
2. サイドバーのボタンからパネルを開きます。未サインインなら、ボタンひとつで IDE 内蔵のターミナルが
   処理します。
3. メッセージを書きます。ファイルやフォルダは入力欄に落とし、`@` でプロジェクトのファイル、`/` で
   コマンド、`!` で自分のシェルを実行。
4. エディタで選択して「Send to Amazing Claude Code GUI」を選ぶと、貼り付けた文字列ではなく、ファイル
   と行を正確に指す参照が送られます。
5. 入力欄の下の三つのボタンがモデル・思考の強さ・権限モードで、どれも今見ているタブだけのものです。

## パネルにあるもの

- **ファイルは打つのではなく、指し示す。** ドラッグして落とす、`@` と打って選ぶ、スクリーン
  ショットや長いログをそのまま貼る - どれもチップになるので、打ち間違えようがありません。
- **コードは住所ごと渡る。** 行を選んで「Send to Amazing Claude Code GUI」。エージェント
  は文脈のない断片ではなく、その周りにある本物のファイルを読みます。
- **パスはファイルを開く。** 会話のどこにあるパスでも - カードの見出し、回答、エラー、自分の
  メッセージのものでも - 指定された行でエディタにファイルが開き、編集を指すパスならその編集の
  場所が開きます。
- **回答のどの部分も取っ手になる。** 次のメッセージに引用する、その地点から会話を分岐する、
  チャットの上に最大三件までピン留めする、あるいは送信済みのメッセージを入力欄に戻して直して
  から再送する。
- **モデル・思考の強さ・権限モードは会話の途中で切り替わる**、タブごとに独立していて、再起動は
  不要です。新しいチャットが何で始まるかは自分で設定でき、自分のサーバーのモデルを手動で追加
  することもできます。
- **MCP サーバー・プラグイン・マーケットプレイス**はそれぞれ専用の画面を持ち、どのサーバーが
  動いているか、どれがサインインを求めているか、どれが落ちていて、なぜかが分かります。
- **履歴** - このプロジェクトの過去の会話。ターミナルで始めたものも含み、末尾から開いて、
  必要に応じて過去へページをさかのぼれます。
- **キュー** - ターンが進んでいる間に書いたメッセージを並べておき、ドラッグで順番を変えられ
  ます。
- **`!` で自分のシェルのコマンドを実行**、その出力は次のメッセージと一緒に届き、ターンも
  権限確認も消費しません。
- **プロンプトの改善** - きらめきボタンが下書きを別の実行で書き直します。会話のコンテキスト
  は減らず、ボタンひとつで自分の言葉に戻せます。
- **音声入力** - ご自身の Deepgram キーで。ホットキーを押している間だけ有効で、エディタから
  でも使えます。
- **サウンド通知** - 鳴らす価値のある七つの場面だけ、しかも見ていないときだけ。
- **統計** - 時間、習慣、実績。画像にして共有できます。
- **十言語** - 既定では IDE の言語に従います。
- **未保存のバッファ**はターンの前に書き出され、エージェントが変更したファイルはすぐに読み
  直されます。
- **エディタのタブではなく、サイドパネル**、ウィンドウのどの端にも置けます。数字キーで選択肢
  を選び、Shift+Tab でモードを切り替え、Escape でターンを止められます。

## プライバシーと透明性

- **すべて自分のマシンで動く。** 間にプロキシも、こちらのサーバーもありません。Claude へのサイン
  インは CLI のもので、プラグインが読むことも、ディスクの API キーを探し回ることもありません。
- **テレメトリなし、解析なし、アカウントなし。** リモートアクセスがオフなら、外に出るのはご自身が
  書いて送るフィードバックだけ。送る前に、その全文をボタンひとつで確認できます。
- **権限のルールはあなたのもの。** 何を確認するかは、あなたの設定・ルール・フックに従って CLI が
  決めます。プラグインが独自のフックを足すことも、画面に出ているより緩いモードでセッションを始める
  こともありません。
- **ソースは公開**（GitHub、Elastic License 2.0）。マシンから出る可能性のあるものは
  [プライバシーポリシー](https://relay.mzpizote.com/privacy)にすべて挙げてあります。

## 動作環境

インストール済みでサインインした Claude Code と、2026.1 以降の JetBrains IDE（Android Studio を
含む）。Android Studio には内蔵ブラウザがないため、IDE が JetBrains のブラウザプラグインを本
プラグインと一緒に入れるか尋ねます。
