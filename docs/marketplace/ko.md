# Amazing Claude Code GUI

**JetBrains IDE 안에서 Claude Code를 제대로 된 채팅 패널로.** 터미널 스크롤 대신 카드로, 경로를
타이핑하는 대신 파일을 가리키는 방식으로, 그것도 코드 바로 옆에서.

이미 설치되어 있는 Claude Code CLI를 그대로 구동합니다. 계정, 모델, 슬래시 명령, 권한 규칙, MCP
서버, 스킬이 전부 그대로 따라옵니다. 중간에 프록시도 없고, 저희 계정을 만들 필요도 없습니다.

## 왜 이 플러그인인가

- **한 번 적어두면 계속 대신 돌아가는 작업 한 바퀴.** 시나리오: 카드 몇 개로 이루어지며, 각 카드는 그 자체로 하나의 Claude 세션입니다 - 구현, 리뷰, 수정,
  테스트 실행 - 한 바퀴 넘게 돌 수 있는 단계들로 이루어지고, 메인 스레드가 그 단계들을 따라가며 각각이 무엇을 찾아냈는지 판단합니다. 버튼 하나로 하나를 실행하거나, 세
  개의 티켓에 맞서 한 번에 세 개를 실행하거나, 질문에 대한 답을 미리 채워둔 채 매주 평일 아침 9시에 맞춰 예약 실행할 수 있습니다. 이 작업 한 바퀴를 한 문장으로
  설명하면 Claude가 프로젝트를 읽고 양식을 작성해 줍니다.
- **휴대폰에서 쓸 수 있는 건 "예" 버튼 하나가 아니라 패널 전체입니다.** 권한 요청이나 계획에 답하고, 닫혀 있는 프로젝트를 열고, 어제 나눈 대화를 읽고, 분기하고,
  모델과 사고 강도를 바꾸고, 계정을 전환하고, 커넥터에 로그인하고, 음성으로 입력하고, 시나리오가 돌아가는 모습을 지켜보며 막힌 곳을 풀어줄 수 있습니다. 기본값은 꺼짐,
  QR 코드로 페어링, 한 글자도 읽지 못하는 릴레이를 거치는 종단 간 암호화, 탭 한 번으로 해지.
- **Claude 계정 여러 개를 클릭 한 번으로 전환합니다.** 로그아웃 없이 한 대의 컴퓨터에서 업무용과 개인용 계정을 모두 씁니다. 각 줄에는 그 계정의 5시간 한도와
  주간 한도가 얼마나 남았는지 표시되고, Select를 누르면 열려 있는 모든 대화가 그 계정으로 옮겨갑니다.
- **프로젝트 안의 모든 대화를 검색합니다.** 접두어, 오타, 어간, 따옴표로 묶은 구문까지 - 이 대화만 또는 전체 대화 중에서, 찾은 메시지가 있는 대화로 바로
  이동합니다. 단어만으로 부족하면 찾는 것을 설명하세요 - Claude가 대신 대화를 읽어봅니다.
- **하는 일이 모두 화면에 보입니다.** 소요 시간이 붙은 모든 도구 호출, 펼쳐진 diff로 보이는 모든 편집, 서브에이전트와 워크플로 에이전트 전체 무리(각 에이전트의
  트랜스크립트도 클릭 한 번이면 볼 수 있습니다), 하나씩 지워지는 할 일 목록, 그리고 이번 턴에 든 비용까지. 과부하이거나 한도에 걸린 API는 침묵이 아니라 이유와
  카운트다운이 적힌 카드로 나타납니다.
- **아무도 당신 대신 답하지 않고, 아무것도 사라지지 않습니다.** 권한 요청도, 계획도, 질문도 필요한 만큼 기다립니다 - 시간 제한도 자동 진행도 없습니다. 패널을
  접거나 프로젝트를 전환해도 대화는 계속 진행되고, 턴이 도는 동안 쓴 메시지는 IDE가 관리하는 대기열에서 기다립니다.
- **Android Studio도 포함되며**, 2026.1 이상의 모든 JetBrains IDE에서 동작합니다.

## 시작하기

1. Claude Code를 설치하고 터미널에서 동작하는지 확인하세요. 패널이 구동하는 것이 바로 그 CLI입니다.
2. 사이드바의 버튼으로 패널을 엽니다. 로그인이 되어 있지 않다면 버튼 하나로 IDE 내장 터미널에서
   처리됩니다.
3. 메시지를 씁니다. 파일이나 폴더는 입력창에 끌어다 놓고, `@`는 프로젝트 파일, `/`는 명령, `!`는 내
   셸에서 실행입니다.
4. 에디터에서 코드를 선택하고 "Send to Amazing Claude Code GUI"를 고르면, 붙여넣은 텍스트가 아니라
   파일과 줄을 정확히 가리키는 참조가 전달됩니다.
5. 입력창 아래의 세 버튼이 모델, 사고 강도, 권한 모드이며, 각각 지금 보고 있는 탭에만 적용됩니다.

## 패널에 더 있는 것

- **파일은 타이핑하지 말고 가리키세요.** 끌어다 놓거나, `@`를 입력해 고르거나, 스크린샷이나 긴 로그를 붙여넣으세요 - 무엇이든 오타가 날 수 없는 칩으로 들어갑니다.
- **코드는 주소와 함께 보냅니다.** 줄을 선택하고 "Send to Amazing Claude Code GUI"를 누르면, 에이전트는 맥락 없는 조각이 아니라 그 주변의
  실제 파일을 읽습니다.
- **경로는 파일을 엽니다.** 대화 어디에 있는 경로든 - 카드 제목, 답변, 오류 메시지, 직접 쓴 메시지 - 그 경로가 가리키는 줄에서 에디터로 파일을 엽니다. 편집
  결과의 경로는 편집 위치 자체를 엽니다.
- **답변의 어느 부분이든 손잡이로 쓸 수 있습니다.** 다음 메시지에 인용하거나, 바로 그 지점에서 대화를 분기하거나, 대화 위에 최대 세 개까지 메시지를 고정하거나, 보낸
  메시지를 입력창으로 다시 가져와 고쳐서 다시 보낼 수 있습니다.
- **모델, 사고 강도, 권한 모드는 대화 도중에 바뀝니다**, 탭마다 따로, 아무것도 재시작하지 않고요. 새 대화가 무엇으로 시작할지는 직접 정할 수 있고, 직접 운영하는
  서버의 모델도 손으로 추가할 수 있습니다.
- **MCP 서버, 플러그인, 마켓플레이스**는 각각 전용 화면을 가지고 있어, 어떤 서버가 떠 있는지, 어떤 서버가 로그인을 요구하는지, 어떤 서버가 왜 죽었는지 볼 수
  있습니다.
- 터미널에서 시작한 것까지 포함한 이 프로젝트의 지난 대화 **기록**을 끝에서부터 열어 보고, 필요할 때 앞으로 페이지를 넘겨 불러옵니다.
- 턴이 도는 동안 쓴 메시지를 담아두는 **대기열** - 끌어서 순서를 바꿀 수 있습니다.
- **`!`는 내 셸에서 명령을 실행하며**, 그 결과는 다음 메시지에 함께 실려 가고, 턴도 권한 요청도 소모하지 않습니다.
- **프롬프트 다듬기** - 반짝임 버튼이 초안을 별도의 실행으로 고쳐 씁니다. 대화의 컨텍스트는 쓰지 않으며, 버튼 하나로 원래 쓴 말로 되돌아갑니다.
- 직접 발급한 Deepgram 키로 쓰는 **음성 입력** - 단축키를 누르고 있으면 되고, 에디터에서도 됩니다.
- 소리를 낼 만한 일곱 순간을 위한 **알림음** - 그것도 이미 보고 있지 않을 때만.
- 시간과 습관, 업적을 모은 **통계** - 이미지로 공유할 수 있습니다.
- **열 개 언어**를 지원하며, 기본값은 IDE 언어를 따라갑니다.
- **저장하지 않은 편집 내용**은 턴 시작 전에 디스크에 기록되고, 에이전트가 바꾼 파일은 IDE가 곧바로 다시 읽습니다.
- **에디터 탭이 아니라 사이드 패널**이며, 창의 어느 가장자리에나 붙일 수 있습니다. 숫자 키로 옵션을 고르고, Shift+Tab으로 모드를 순환하고, Escape로 턴을
  멈춥니다.

## 개인정보와 투명성

- **모든 것이 내 컴퓨터에서 돌아갑니다.** 중간에 프록시도, 저희 서버도 없습니다. Claude 로그인은
  CLI의 것이고, 플러그인이 그것을 읽거나 디스크에서 API 키를 뒤지는 일은 없습니다.
- **텔레메트리도, 분석도, 계정도 없습니다.** 원격 접속이 꺼져 있으면 밖으로 나가는 것은 직접 쓰고
  보내는 피드백뿐이며, 보내기 전에 그 전문을 버튼 하나로 확인할 수 있습니다.
- **권한 규칙은 계속 당신 것입니다.** 무엇을 물어볼지는 당신의 설정과 규칙, 훅에 따라 CLI가
  정합니다. 플러그인은 자체 훅을 얹지 않고, 화면에 보이는 것보다 느슨한 모드로 세션을 시작하지도
  않습니다.

설치 후 로그인된 Claude Code, 그리고 2026.1 이상의 JetBrains IDE(Android Studio 포함). Android
Studio에는 내장 브라우저가 없어서, IDE가 JetBrains의 브라우저 플러그인을 이 플러그인과 함께 설치할지
물어봅니다.
