# Amazing Claude Code GUI

**Claude Code повноцінною панеллю прямо у вашій IDE від JetBrains.** Картки замість терміналу з
прокруткою, файли, на які показуєш, замість шляхів, які набираєш, - і код поряд.

Панель запускає той самий Claude Code CLI, що вже стоїть на машині, тож разом з нею приїжджає все
звичне: ваш акаунт, моделі, слеш-команди, правила дозволів, сервери MCP і скіли. Без проксі і без
нашого акаунта.

## Чому саме ця панель

- **Круг робіт, записаний один раз і виконуваний за вас.** Сценарії: кілька карток, у кожної -
  своя сесія Claude - реалізувати, перевірити, виправити, прогнати тести - в етапах, які можуть
  повторюватися не один раз, а головний потік проходить по них і судить, що знайшла кожна.
  Запустіть один натисканням кнопки, три одразу - проти трьох задач, або за годинником о дев'ятій
  кожного буднього дня, з відповідями на його запитання, підготовленими заздалегідь. Опишіть круг
  робіт одним реченням - і Claude прочитає проєкт і напише форму.
- **Уся панель з телефону, а не лише кнопка «так».** Дайте відповідь на дозвіл чи план, відкрийте
  закритий проєкт, прочитайте вчорашню розмову, зробіть форк, змініть модель і зусилля,
  перемкніть акаунт, увійдіть у конектор, продиктуйте повідомлення, подивіться, як іде сценарій, і
  розблокуйте його. Вимкнено за замовчуванням, пара за QR-кодом, наскрізне шифрування через релей,
  який не прочитає жодного слова, відкликання доступу одним дотиком.
- **Кілька акаунтів Claude перемикаються в один клік.** Робочий і особистий на одній машині без
  виходу з жодного. Кожен рядок показує залишок п'ятигодинного вікна цього акаунта і його
  тижневого вікна, а Select переводить на нього всі відкриті розмови.
- **Пошук по всіх розмовах проєкту.** Початки слів, помилки, основи слів, фрази в лапках; цей чат
  або всі одразу, зі стрибком прямо до повідомлення в його розмові. Коли слів не вистачає, опишіть,
  що шукаєте, - і Claude прочитає розмови за вас.
- **Усе, що відбувається, видно на екрані.** Кожен виклик інструмента - з тривалістю, кожна
  правка - відкритим діфом, субагенти і цілі флоти агентів workflow, з розмовою кожного агента в
  один клік, список задач, що позначається зробленим на очах, і ціна ходу. Перевантажений або
  впертий у ліміт API - це картка з причиною і зворотним відліком, а не тиша.
- **Ніхто не відповідає за вас, і нічого не втрачається.** Дозвіл, план чи питання чекають стільки,
  скільки потрібно - без таймера, без автопродовження. Розмови тривають, навіть якщо панель
  згорнута чи проєкт перемкнутий, а повідомлення, написані під час ходу, чекають у черзі, яку
  тримає IDE.
- **Android Studio теж**, як і будь-яка IDE від JetBrains починаючи з 2026.1.

## З чого почати

1. Встановіть Claude Code і переконайтеся, що він працює в терміналі - панель запускає саме цей
   CLI.
2. Відкрийте панель кнопкою на бічній панелі інструментів. Якщо вхід не виконано, одна кнопка
   зробить це у вбудованому терміналі IDE.
3. Напишіть повідомлення. Перетягніть файли чи папки в поле, наберіть `@` для файлу проєкту, `/`
   для команди, `!` для запуску в вашій оболонці.
4. Виділіть код у редакторі й оберіть «Send to Amazing Claude Code GUI», щоб надіслати точне
   посилання на файл і рядок замість вставленого тексту.
5. Модель, зусилля і режим дозволів - три кнопки під полем, і кожна належить тій вкладці, на яку
   ви дивитеся.

## Що ще є в панелі

- **На файли показують, а не набирають їх.** Перетягніть файл, наберіть `@`, щоб обрати його,
  вставте скріншот чи довгий лог - кожен стає капсулою, у якій не можна помилитися.
- **Код їде разом зі своєю адресою.** Виділіть рядки, «Send to Amazing Claude Code GUI» - і агент
  прочитає справжній файл навколо них, а не фрагмент без контексту.
- **Шляхи відкривають файли.** Шлях будь-де в розмові - у шапці картки, у відповіді, у тексті
  помилки, у вашому власному повідомленні - відкриває файл у редакторі на названому рядку; у
  правки він відкривається на місці самої правки.
- **Візьміть будь-яку частину відповіді.** Процитуйте її в наступному повідомленні, зробіть форк
  розмови рівно з цього місця, закріпіть до трьох повідомлень над стрічкою або поверніть надіслане
  повідомлення в поле, щоб виправити й надіслати знову.
- **Модель, зусилля і режим змінюються посеред розмови** - у кожної вкладки свої, без
  перезапуску. З чого стартує новий чат - вирішуєте самі й закріплюєте, а модель зі свого сервера
  можна додати вручну.
- **MCP-сервери, плагіни і маркетплейси** - на окремих екранах: який сервер піднято, якому
  потрібен вхід, який впав і чому.
- **Історія** минулих розмов цього проєкту, включно з розпочатими в терміналі, відкривається з
  кінця і підвантажується сторінками назад за запитом.
- **Черга** для повідомлень, написаних під час ходу; порядок змінюється перетягуванням.
- **`!` запускає команду у вашій оболонці**, і її вивід їде разом з наступним повідомленням, не
  витрачаючи хід і не питаючи дозволу.
- **Покращення промпта** - зірочка переписує ваш чернетковий текст окремим запуском, не
  витрачаючи контекст розмови, а одна кнопка повертає ваші слова.
- **Голосове введення** за вашим власним ключем Deepgram: тримайте гарячу клавішу навіть прямо з
  редактора.
- **Звукові сигнали** на сім моментів, які того варті, - і лише коли ви й так не дивитеся.
- **Статистика** годин, звичок і досягнень, якою можна поділитися картинкою.
- **Десять мов**, за замовчуванням - як у вашій IDE.
- **Ваші незбережені буфери** записуються перед ходом, а файли, які змінив агент, IDE одразу
  перечитує.
- **Бічна панель, а не вкладка редактора**, біля будь-якого краю вікна; цифри обирають варіант,
  Shift+Tab перемикає режим, Escape зупиняє хід.

## Приватність і прозорість

- **Усе працює на вашій машині.** Ніякого проксі й ніякого нашого сервера посередині. Вхід у
  Claude належить CLI - плагін ніколи його не читає і не шукає ключі API на вашому диску.
- **Жодної телеметрії, жодної аналітики, жодного акаунта.** Коли віддалений доступ вимкнено,
  назовні йде лише звіт про проблему, який ви самі написали й надіслали, - і одна кнопка заздалегідь
  показує його точний текст.
- **Ваші правила дозволів лишаються вашими.** Про що питати, вирішує CLI за вашими налаштуваннями,
  правилами і хуками. Плагін не додає жодного власного хука і ніколи не запускає сесію в м'якшому
  режимі, ніж той, що показаний на екрані.

## Вимоги

Встановлений Claude Code з виконаним входом, і будь-яка IDE від JetBrains починаючи з 2026.1,

запропонує встановити плагін браузера від JetBrains разом із цим.
