# Amazing Claude Code GUI

**把 Claude Code 变成 JetBrains IDE 里的聊天面板。** 用卡片代替终端里的滚动输出，用手指指向文件
代替手敲路径，代码就在旁边。

它驱动的正是你机器上已装好的 Claude Code CLI，所以账号、模型、斜杠命令、权限规则、MCP 服务器和
技能都原样跟过来。没有中间代理，也不需要注册我们的账号。

## 为什么选它

- **一套工作流程，写一次，以后都由它替你跑。** 场景功能：几张卡片，每张卡片背后都是一次独立的 Claude 会话，
  负责实现、评审、修复或跑测试，这些步骤分成几个阶段，阶段可以循环不止一次，由一条主线负责串联它们，并判断每一步查到了什么。
  可以点一下按钮只跑一次，也可以同时对三个工单跑三次，或者设定在每个工作日的上午九点自动运行，并提前把它会问的问题答好。
  用一句话描述这套流程，Claude 就会读懂项目，把表单写出来。
- **整个面板都能在手机上用，而不只是一个「同意」按钮。** 可以回答权限请求或计划、打开一个已经关闭的项目、读昨天的对话、
  分叉、切换模型和思考强度、切换账号、登录某个连接器、口述、看着一次场景运行并在它卡住时解锁继续。默认关闭，扫码配对，
  全程端到端加密，经手的中转服务器读不到一个字，一键即可撤销。
- **多个 Claude 账号，一键切换。** 工作账号和个人账号可以在同一台机器上共存，谁都不用登出。每一行都显示这个账号五小时窗口和这一周还剩多少额度，
  点 Select 就能把所有打开的对话都转移到它上面。
- **跨越项目里的每一次对话搜索。** 支持前缀、拼写错误、词干、引号里的完整短语；可以只搜当前对话，也可以搜全部对话，
  点一下就能跳到消息所在的那次对话里。如果几个关键词说不清楚，描述一下你要找什么，Claude 会替你读完所有对话。
- **它做的每件事都摆在屏幕上。** 每一次工具调用连同耗时，每一次编辑都是可以展开的差异，子智能体和一次工作流调用里的整支智能体队伍，
  每个智能体自己的记录点一下就能看到，逐条勾掉的待办清单，还有这一轮花了多少。API 过载或触发限流时，出现的是一张写明原因和倒计时的卡片，
  而不是莫名其妙的沉默。
- **没有人替你回答，也不会丢掉任何东西。** 权限请求、计划或提问会一直等你，要多久等多久，既没有超时，也不会自动继续。
  折叠面板或者切到别的项目，对话依然在继续，一轮进行中途写下的消息，会留在 IDE 保管的队列里等着。
- **也支持 Android Studio**，以及 2026.1 起的所有 JetBrains IDE。

## 快速上手

1. 装好 Claude Code，并确认它在终端里能正常运行：面板驱动的就是这个 CLI。
2. 从侧边栏的工具窗口按钮打开面板。若还没登录，一个按钮就会在 IDE 自带的终端里完成登录。
3. 写下你的消息：把文件或文件夹拖进输入框，`@` 引用项目文件，`/` 唤出命令，`!` 在你自己的 shell
   里执行。
4. 在编辑器里选中代码并右键选择「Send to Amazing Claude Code GUI」，发过去的是精确的文件与行号
   引用，而不是粘贴的文本。
5. 输入框下面的三个按钮是模型、思考强度和权限模式，每个都只属于你正在看的那个标签页。

## 面板里还有什么

- **指向文件，而不是敲出路径。** 把文件拖进来、输入 `@` 挑选它、粘贴一张截图或一段很长的日志，每一样都会变成一枚不会打错的胶囊。
- **发送代码，带着它的地址。** 选中几行代码，选择「Send to Amazing Claude Code GUI」，
  智能体读到的是这几行周围真实的文件，而不是一段没有来龙去脉的片段。
- **路径能直接打开文件。** 对话里任何地方出现的路径，无论是卡片标题、回答、报错，还是你自己发的消息，都会在编辑器里打开对应文件，
  并跳到它标出的那一行；如果这个路径指向一次编辑，打开的就是那次编辑本身。
- **抓住回答里的任意一部分。** 把它引用到下一条消息里，从那个精确位置分叉出对话，最多可以把三条消息置顶在对话上方，
  或者把已经发送的消息收回输入框，改好后重新发送。
- **模型、思考强度和权限模式可以在对话中途切换**，各标签页互不影响，无需重启任何东西。新对话默认使用哪个模型由你自己设定，
  你自己服务器上的模型也可以手动添加进来。
- **MCP 服务器、插件和插件市场**都有各自专属的界面：哪个服务器已经启动，哪个还需要登录，哪个挂了、为什么挂了。
- **历史**：本项目过去的对话，包括在终端里开始的那些，从末尾打开，按需向前翻页加载更早的内容。
- **队列**：某一轮还在进行时写下的消息会进入队列，可以拖动调整顺序。
- **`!` 在你自己的 shell 里运行命令**，输出会随你的下一条消息一起发送，不占用一轮对话，也不会弹出权限请求。
- **改写提示词**：星形按钮用一次独立的运行改写你的草稿，不消耗对话本身的上下文，一个按钮就能把你原本的话找回来。
- **语音输入**：用你自己的 Deepgram 密钥，按住热键即可开始，在编辑器里也能用。
- **声音提醒**：值得出声的七个时刻，而且只在你没有正看着的时候才响。
- **统计**：小时数、习惯与成就，可以做成图片分享出去。
- **十种语言**，默认跟随你的 IDE。
- **你未保存的编辑器缓冲区**会在一轮开始前写入磁盘，智能体改过的文件也会被 IDE 立刻重新读取。
- **是侧边面板，不是编辑器标签页**，可以停靠在窗口的任意一边；数字键可以选择选项，Shift+Tab 循环切换权限模式，
  Escape 用来停止这一轮。

## 隐私与透明

- **一切都在你自己的机器上运行。** 没有中间代理，中间也没有我们的服务器。Claude 的登录状态属于
  CLI，插件从不读取它，也不会在你的磁盘上翻找 API 密钥。
- **没有遥测、没有分析、没有账号。** 关闭远程访问后，唯一会离开机器的，只有你亲手写下并发送的
  反馈报告，而且发送前有个按钮会把它的全文给你看。
- **你的权限规则仍然是你的。** 该不该问由 CLI 按你的设置、规则和钩子决定。插件不添加自己的钩子，
  也绝不会用比屏幕上显示的更宽松的模式启动会话。
- **源码公开**在 GitHub 上，采用 Elastic License 2.0，
  [隐私政策](https://relay.mzpizote.com/privacy)列出了一切可能离开这台机器的东西。

## 环境要求

已安装并登录的 Claude Code，以及 2026.1 起的任意 JetBrains IDE，包括 Android Studio。Android
Studio 自身不带内嵌浏览器，因此 IDE 会提示把 JetBrains 的浏览器插件和本插件一起装上。
