# Amazing Claude Code GUI

**把 Claude Code 变成 JetBrains IDE 里的聊天面板。** 用卡片代替终端里的滚动输出，用手指指向文件
代替手敲路径，代码就在旁边。

它驱动的正是你机器上已装好的 Claude Code CLI，所以账号、模型、斜杠命令、权限规则、MCP 服务器和
技能都原样跟过来。没有中间代理，也不需要注册我们的账号。

## 为什么选它

- **指向文件，而不是敲出路径。** 把文件拖进来、输入 `@` 从项目里挑一个、直接粘贴截图，每一个都
  变成一枚不会打错的胶囊。
- **代码连着地址一起发过去。** 在编辑器里选中几行，用「Send to Amazing Claude Code GUI」，智能体
  读到的是文件本身及其上下文，而不是一段没有来龙去脉的片段。
- **回答的任意一段都是把手。** 引用到下一条消息里，或者从那个位置分叉出新的对话，原来的对话
  原样保留。
- **看得见它在干什么。** 工具调用及其耗时、带增删行数的差异、逐条勾掉的待办清单、计划、子智能体、
  一次工作流调用里的整支智能体队伍，以及这一轮花了多少。
- **不会有莫名其妙的沉默。** API 过载或触发限流时，会出现一张卡片：原因、第几次重试、下一次的
  倒计时。
- **没有人替你回答。** 权限请求、计划和提问会一直等你，要多久等多久，既没有超时，也没有自动继续。
- **是侧边面板，不是编辑器标签页**，可以停靠在窗口的任意一边。
- **对话比面板活得更久。** 折叠面板、切到别的项目、再回来，智能体一直在干活，排队的消息也还在
  队列里。
- **模型、思考强度和权限模式可以在对话中途切换**，各标签页互不影响，无需重启任何东西。
- **可以用手机回答。** 默认关闭，扫码配对，端到端加密，一键撤销。
- **也支持 Android Studio**，以及 2026.1 起的所有 JetBrains IDE。

## 快速上手

1. 装好 Claude Code，并确认它在终端里能正常运行。
2. 从侧边栏打开面板；若还没登录，一个按钮就会在 IDE 自带的终端里完成登录。
3. 开始写：把文件拖进输入框，`@` 引用项目文件，`/` 唤出命令，`!` 在你自己的 shell 里执行。输入框
   下面的三个按钮就是模型、思考强度和权限模式。

## 面板里还有什么

- **历史**：本项目过去的对话，包括在终端里开始的那些。
- **队列**：一轮还在跑的时候写下的消息，可以拖动调整顺序。
- **改写提示词**：星形按钮用一次独立的运行改写草稿，不消耗当前对话的上下文，一个按钮就能把你原本
  的话找回来。
- **语音输入**：用你自己的 Deepgram 密钥，按住热键即可，在编辑器里也能用。
- **声音提醒**：值得出声的七个时刻，而且只在你没看着的时候响。
- **统计**：小时数、习惯与成就，可以做成图片分享。
- **九种语言**，默认跟随你的 IDE。
- **未保存的编辑器缓冲区**会在一轮开始前写入磁盘，智能体改过的文件也会被 IDE 立刻重新读取。

## 隐私与透明

- **一切都在你自己的机器上运行。** 没有中间代理，中间也没有我们的服务器。Claude 的登录状态属于
  CLI，插件从不读取它，也不会在你的磁盘上翻找 API 密钥。
- **没有遥测、没有分析、没有账号。** 关闭远程访问后，唯一会离开机器的，只有你亲手写下并发送的
  反馈报告，而且发送前有个按钮会把它的全文给你看。
- **你的权限规则仍然是你的。** 该不该问由 CLI 按你的设置、规则和钩子决定。插件不添加自己的钩子，
  也绝不会用比屏幕上显示的更宽松的模式启动会话。
- **源码公开**在 GitHub 上，采用 Elastic License 2.0，
  [隐私政策](https://relay.mzpizote.com/privacy)列出了一切可能离开这台机器的东西。

## 环境要求

已安装并登录的 Claude Code，以及 2026.1 起的任意 JetBrains IDE，包括 Android Studio。Android
Studio 自身不带内嵌浏览器，因此 IDE 会提示把 JetBrains 的浏览器插件和本插件一起装上。
